Royal Wedding Invitation 💍✨

A beautiful and elegant double-wedding invitation website designed to celebrate two sisters' special day.

💖 About the Project

This project is a digital wedding invitation card created using HTML, CSS, and JavaScript. It features a royal aesthetic, elegant typography, decorative elements, and background music to create a memorable invitation experience.

✨ Features

- Elegant and royal wedding card design
- Hindi typography using Google Fonts
- Animated invitation opening experience
- Bride and groom photo placeholders
- Wedding gallery placeholders
- Background music with a music button
- Responsive design for mobile and desktop screens
- Shareable website link

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts
- SVG graphics
- MP3 audio

📁 Project Structure

- "index.html" — Main wedding invitation webpage
- "style.css" — Styling, layout, and animations
- "script.js" — Interactive features
- "images/" — Wedding graphics and photo placeholders
- "weddingaudio1.mp3" — Background music
- "README.txt" — Project documentation

🚀 How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Run "index.html" using Live Server.
4. Enjoy the digital wedding invitation.

🌐 Deployment

This website can be hosted using GitHub Pages and shared with friends and family through a public link.
